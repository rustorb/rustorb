# rustorb-cdr

CDR (Common Data Representation) encoder and decoder: the IDL primitive and
constructed types with the GIOP alignment rules, both byte orders, wide
strings (UTF-16), encapsulations, shared octet sequences, `long double` as
IEEE 754 binary128 and the valuetype encoding (tags, indirections, chunks).

rustorb is a CORBA ORB written in Rust, with Python, C++ and Java bindings.
See the [repository](https://github.com/rustorb/rustorb) for the other crates,
the bindings and the documentation.

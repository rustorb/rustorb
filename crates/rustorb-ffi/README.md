# rustorb-ffi

The stable C ABI of rustorb (`include/rustorb/rustorb.h`), on which the C++
binding and the Java binding (through the FFM API) are built. Build it as a
static or shared library (`librustorb_ffi`).

rustorb is a CORBA ORB written in Rust, with Python, C++ and Java bindings.
See the [repository](https://github.com/rustorb/rustorb) for the other crates,
the bindings and the documentation.
